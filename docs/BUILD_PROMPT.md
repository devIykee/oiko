# Oiko build prompt (condensed copy for contributors)

The original build prompt was given to the coding agent in chat. This file keeps the parts every workstream needs, nearly verbatim. Where the "Follow-up: personal finance" section at the bottom conflicts with earlier sections, the follow-up wins. Contract and HTTP interfaces are frozen in `docs/interfaces/`.

## 1. What Oiko is

Oiko is a personal finance app with your name on it, built on stablecoins (USDC, USDT) on NEAR. You sign in, claim `ada.oiko.near` (testnet: `ada.oiko.testnet`), and share a pay link. Anyone can pay that link from any chain (NEAR Intents 1Click). Every incoming payment is split automatically into pots: Spend (flex, withdraw any time, under 60 s), Savings (autosave), Bills, Locked (enforced by contract, nobody can break it, not even you or the Oiko team), and Goals. Pots can optionally earn variable yield through Rhea lending, guarded by an on-chain utilization check. Ajo circles (rotating savings) with contract-enforced order and bonds. Oiko has **no built-in AI**: users connect the AI agent they already use, which reads finances and acts inside limits the user sets and the vault contract enforces. Only USDC and USDT. No naira or fiat rails. Non-custodial.

## 3. Product rules that override the PRD

1. Web only (Next.js), excellent on a ~$100 Android phone over slow 3G/4G and on desktop.
2. Locks are unbreakable: identity account `ada.oiko.near` holds the user's keys; funds live in `vault.ada.oiko.near` which has **no access keys** (except agent function-call keys it adds itself) and immutable code with no upgrade method.
3. Vault code via NEAR Global Contracts if available; publish the code hash on the Trust page.
4. Receiving does not depend on `ft_on_transfer`: permissionless idempotent `sync()`.
5. Utilization guard on-chain before supplying to Rhea (refuse above 92%, configurable, never above 95%).
6. **No fake numbers anywhere.** Never hardcode an APY, user count or TVL. Rates read live and labelled "today's rate". Stats show "n/a" if unavailable.
7. **No built-in AI.** No LLM SDKs, no model keys, no chat box. CI check fails if an LLM SDK or LLM API host appears in apps/ or services/.
8. Personal accounts only. No business mode.
9. **Stablecoins, not dollars.** Never say or imply "dollars", "USD", "dollar savings". Amounts are number + ticker: `120.50 USDC`. Never a `$` prefix. Home total shows `1,240.50` with the label "USDC + USDT" and a per-token breakdown. Explainer sentence (only allowed exception): "USDC and USDT are stablecoins designed to track the US dollar. They are not dollars and are not bank deposits. They can lose their peg and issuers can freeze them." Naira line: "≈ ₦… (reference only)" from a sourced USDT/NGN rate. Pay page asks "How much USDT?". Invest pad: "Buy with USDT/USDC". Caps/goals/ajo amounts in a token ("50 USDT per week").
10. Invest tab: XAUT only, behind a flag; US stocks "coming soon, not available to US persons".
